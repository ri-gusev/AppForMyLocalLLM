# LocalAgent

Windows-приложение на C++17 с базовым графическим чатом и локальной моделью
`qwen3:8b` через Ollama (`localhost:11434/api/chat`). Облачные модели
и API-ключи не используются.

Введите сообщение и нажмите Enter или «Отправить». Shift+Enter добавляет
новую строку. Ответы и история отображаются в верхней части окна.
Во время запроса окно остаётся отзывчивым; следующая отправка доступна
после ответа. Ошибка показывается в чате, после неё можно повторить запрос.
Пустые сообщения пропускаются. Для выхода закройте окно.

История успешных сообщений и ответов передаётся модели при каждом запросе
и хранится в памяти до завершения программы. Длина разговора ограничена
контекстным окном модели; автоматического сокращения истории пока нет.

## Сборка и запуск

Нужны CMake 3.20+, MinGW-w64 (g++ и mingw32-make в PATH), запущенный Ollama
и установленная модель `qwen3:8b`.

```powershell
cmake --preset mingw-debug
cmake --build --preset mingw-debug
.\build\local_agent.exe
```

## Структура

- `src/main.cpp` — запуск Windows-приложения.
- `include/chat_window.h`, `src/chat_window.cpp` — окно на Win32 и фоновая отправка.
- `include/ollama_client.h`, `src/ollama_client.cpp` — HTTP-клиент Ollama.
- `third_party/nlohmann/json.hpp` — JSON-библиотека версии 3.11.3 (MIT; лицензия внутри заголовка).
- `CMakeLists.txt`, `CMakePresets.json` — сборка.

HTTP работает через системный Windows WinHTTP. Зависимости при сборке
не скачиваются. Интерфейс поддерживает русский текст; HTTP использует UTF-8.
MinGW-сборка включает C++ runtime в исполняемый файл. Можно запускать
двойным щелчком по `build/local_agent.exe`, без консольного окна.
