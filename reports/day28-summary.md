# День 28: локальная LLM + RAG

Проверено 10 октября 2026 года на текущем компьютере.

Цепочка: вопрос → Ollama `bge-m3` → локальный SQLite-индекс → косинусный
поиск и эвристическое ранжирование → Ollama `qwen3:8b` → окно Windows.
HTTP-запросы идут только на `localhost:11434`, без облачного провайдера.

Использован снимок индекса `AICourse/AIAgentsCourse/document_index.db`:
596 структурных фрагментов, 1024-мерные float32-векторы. Настройки перенесены
из `rag_config.json`: 10 кандидатов, порог 0.45, максимум 4 фрагмента.
Вопрос передаётся в поиск напрямую; облачного переписывания запроса нет.

## Качество

Три вопроса проверялись по два раза в независимых диалогах:

| Вопрос | Результат | Ограничение |
|---|---|---|
| Модель эмбеддингов по умолчанию | Верно: `bge-m3` | Подтверждается найденными исходниками и README |
| Максимальная длина query | Найден лимит `16000` | Модель назвала единицы «символами», хотя `std::string::size()` считает байты |
| Алгоритм rankVectors | Верно: косинусное сходство | Ссылка `[1]` указывает на заголовок с объявлением; реализация сортировки находится в другом переданном фрагменте |

Проверка ожидаемых терминов прошла 6/6. Это не означает идеальную
фактическую точность: обнаружены неточность единиц и недостаточно точная
привязка цитаты. Полные ответы и найденные тексты сохранены в
`day28-local.json`. Автоматической проверки цитат в приложении нет.

## Стабильность и проверки

- 6/6 запросов завершились без транспортных ошибок.
- Для каждого из трёх вопросов два ответа совпали дословно.
- Небольшая выборка не доказывает стабильность длительной работы или
  корректность ответов на другие вопросы.
- Сборка Windows GUI прошла. В скрытом окне проверены пустой ввод,
  отправка, локальный ответ, вывод источника и времени, восстановление кнопки.
- CTest проверил ошибки конфигурации, отсутствующего индекса и схемы;
  отсутствующая БД не создаётся при чтении. Тест не обращается в сеть.
- SQLite `PRAGMA integrity_check`: `ok`.
- Визуальная проверка окна на рабочем столе не проводилась.

## Облачное сравнение

Не выполнялось: в этом приложении облачный провайдер не настроен.
Вывод о превосходстве локальной или облачной модели по этим данным
сделать нельзя.
