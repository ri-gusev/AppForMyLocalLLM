# Индекс RAG

`document_index.db` скопирован согласованным SQLite-снимком из
`D:/Studying/Programming/vibeCodingMyOwnProjects/AICourse/AIAgentsCourse/document_index.db`.
Исходная база не изменялась. На момент переноса содержит 596 структурных
фрагментов, размерность эмбеддингов — 1024. В корпусе есть исходники проекта
и ранее загруженные документы. Это уже проиндексированные данные, а не
автоматически обновляемая копия исходного проекта.

Используется локальная модель эмбеддингов `bge-m3`. Замена модели требует
пересоздания всего индекса, даже если размерность векторов совпадает.
Исходный `document_index.db` открывается только для чтения.
Добавленные пользователем документы сохраняются отдельно в `user_index.db`
рядом с запущенным `.exe`; эта база изменяется приложением и не входит в git.
